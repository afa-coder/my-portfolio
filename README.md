# Awais Farhan Alam | Portfolio

This is a personal portfolio website built with React and Vite to showcase projects, technical skills, and contact details.

## Highlights
- Clean and modern one-page portfolio experience
- Project showcase with detailed modal views
- Resume download and contact form
- Focus on full-stack development, backend engineering, and DevOps practices

## Skills Covered
- Frontend: React, Next.js, Vite, HTML/CSS/JavaScript
- Backend: Node.js, Express.js, NestJS, Python
- Programming: Java, C, C++, Python, JavaScript
- DevOps & Cloud: AWS practices, Docker, Azure practices, CI/CD, system design, AI automation
- Databases: SQL, NoSQL, PostgreSQL, MongoDB

## Featured Projects
- Social Scheduler
- Automated Telecom Quiz Platform
- CyberaHAT
- AI-Based Unique Company Name Generator
- AI Finance Platform

## Run Locally
```bash
npm install
npm run dev
```

## Build for Production
```bash
npm run build
```
